# proyectosica

S.I.C.A sistema inteligente de control de  control alimentario 
Esto es un sistema web para la gestión de inventarios enfocado en la prevención de  caducidad del los productos 
Instrucciones para ejecutar el proyecto:
Tiene dos formas de ejecutar este proyecto
Opción 1 : ejecutar localmente sin servidor 
Descargar este repositorio como archivo ZIP o clonado usando “git clone” 
Abrir el archivo llamado “index.html” en la carpeta descargada 
Ejecutable: haz un clic  sobre el index .html para abrirlo en cualquier navegador moderno (Chrome , Edge , Firefox)
Opcion 2 : ver la versión de la nuve (recomendado)

Herramientas que se utilizó:
HTML estructura del sitio 
CSS estilos responsivos, animaciones y diseño moderno
JavaScript lógica de validación, manejo de datos en localstorage y control de alertas 

Funcionalidades 
Login: registro de usuarios 
Registro de lotes: validación de fechas de caducidad 
Inventario priorizado: visualización en tiempo real del estado de los productos 
Alertas: notificaciones de seguridad
